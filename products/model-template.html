Model Page Sections

Each public model page should use only confirmed model data and applicable product relationships.

01

Product Hero

Model name, category, B2B positioning sentence, verified main image, Request Quote, and Discuss Your Project.

Product Overview

What the product is and where it fits within the coordinated microneedling product line.

03

Key Features

Only verified product features, without unsupported performance or medical claims.

04

Specifications

Model-specific technical fields only; omit unavailable fields rather than using generic values.

05

Compatible Products

Device, cartridge, applicator, accessory, or manual-tool relationships where recorded.

06

Available Options

Pin, head, configuration, logo, color, packaging, manual, insert, or kit options where applicable.

07

Packaging & Supply

Standard packaging and repeat-supply information only where verified for the model.

08

Quality & Documentation

Product-specific certification and documentation language, never a site-wide assumption.
